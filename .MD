CREATING RESTFUL APIS 

GET    /posts - to get data for all posts 
POST   /posts - tp add a new post 
GET    /posts/:id - to get one post ( using id )
PATCH  /posts/:id - to update specific post 
DELETE /posts/:id - to delete specific post 



        // CRUD OPERATIONS  // 
GET  -      to get data - view route 
POST -      to create data - create route 
PUT  -      to update data - update route 
PATCH -     to update data ( partial ) - update route 
DELETE -    to delete data - destroy route
