# 📝 Blog Application (Node + Express + EJS)

A simple blog app where users can create posts, view profiles, report posts, check comments, and manage blog content. The UI works similarly to the preview image provided.

---

## 🛠 Tech Stack

| Tool                  | Use                                          |
| --------------------- | -------------------------------------------- |
| **Node.js**           | Runtime environment                          |
| **Express.js**        | Backend framework for routing and middleware |
| **EJS**               | Template engine used for dynamic rendering   |
| **Nodemon**           | Auto-reloading server during development     |
| **CSS / Frontend UI** | Handles layout and styling                   |

---

## 📥 Clone the Repository

Open terminal and run:

```sh
git clone https://github.com/yourusername/blog-app.git
```

Move inside the project folder:

```sh
cd blog-app
```

---

## 📦 Install Dependencies

```sh
npm install
```

---

## ▶ Run the Project (Using Nodemon)

If you already have nodemon installed globally:

```sh
nodemon app.js
```

If not, install it first:

```sh
npm install -g nodemon
nodemon app.js
```

---

## 🌍 Access the App

Once the server starts, open:

```
http://localhost:3000
```

---

## 📌 How It Works (Based on UI)

✔ User Profile section shows:

* Username
* Followers / Following count
* Bio
* Follow button

✔ Posts Page Includes:

* Post creator username
* Post text
* Buttons for:

  * **Check Profile**
  * **See Details**
  * **See Comments**
  * **Report / Unreport**
  * **Delete Post**

✔ UI supports adding new posts with a clean button: **Add New Post ➕**
